PROYECTO: 🎮 Juego del Ahorcado en Python

Proyecto académico desarrollado en Python que implementa el clásico juego del ahorcado utilizando estructuras de datos, condicionales y ciclos.

---

## 📌 Descripción del Proyecto

Este proyecto consiste en el desarrollo del juego del Ahorcado en consola.  
El usuario debe adivinar una palabra letra por letra antes de que se completen los intentos permitidos.

El programa fue desarrollado aplicando conceptos fundamentales de programación como:

- Variables
- Listas
- Diccionarios
- Condicionales
- Ciclos
- Funciones

---

## 🧠 Objetivos

- Aplicar estructuras de datos en Python
- Implementar lógica condicional
- Utilizar ciclos para controlar el flujo del juego
- Desarrollar un proyecto funcional en consola

---

## 🛠️ Tecnologías utilizadas

- Python 3
- GitHub para control de versiones
